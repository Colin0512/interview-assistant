# 命令模式使用说明

## 设计理念

采用**三击分号(;)**激活命令模式，然后使用**单字母键**执行操作，再**三击分号(;)**退出。

这种设计的优势：

- ✅ 完全隐蔽，看起来像正常打字
- ✅ 不需要功能键，完全用字母和符号
- ✅ 可以连续执行多个操作
- ✅ **伪装打字模式**：命令模式下可以随便打字伪装
- ✅ **随机时间窗口**：每次激活时间不同，避免被识别为规律性操作
- ✅ 单手可操作
- ✅ 不与系统快捷键冲突

---

## 操作流程

```
1. 快速三击 ;（时间窗口动态变化）  → 进入命令模式
2. 按单字母键                      → 执行对应操作
3. 随便打其他字母数字                → 伪装成正常打字（会被忽略）
4. 快速三击 ;                     → 退出命令模式
```

---

## 单字母命令列表

| 字母  | 功能             | 英文助记       |
| ----- | ---------------- | -------------- |
| **S** | 截图并生成新对话 | **S**creenshot |
| **A** | 追加截图         | **A**ppend     |
| **Q** | 停止生成         | **Q**uit       |
| **R** | 语音转录开关     | **R**ecord     |
| **C** | 清除转录文本     | **C**lear      |
| **H** | 隐藏/显示窗口    | **H**ide       |
| **M** | 鼠标穿透开关     | **M**ouse      |
| **J** | 向下滚动         | Vim **J**      |
| **K** | 向上滚动         | Vim **K**      |

**其他所有字母和数字**：在命令模式下会被忽略，可用于伪装打字

## 使用示例

### 场景1：快速截图并提问

```
三击; → S（截图） → 三击;
```

### 场景2：截图 + 伪装打字

```
三击; → S（截图） → 打 "hello world 123" → 三击;
```

✨ 监控软件看到的是：`;; ;Shello world 123;;;`
✨ 实际执行的是：**截图**（其他字符被忽略）

### 场景3：连续操作 + 伪装

```
三击; → S（第一张） → 打 "test" → A（第二张） → 打 "code" → 三击;
```

✨ 看起来像：`;; ;StestAcode;;;`
✨ 实际执行：**截图 → 追加截图**

### 场景4：开启语音 + 截图 + 伪装

```
三击; → R（开始录音） → 打 "function" → S（截图） → 打 "main" → 三击;
```

✨ 完全看不出是在操作工具

## 技术细节

### 三击检测逻辑（隐蔽增强）

- 时间窗口：**动态随机**（300-700ms）
- 每次触发后窗口会随机变化
- ✨ **反检测**：不会被识别为规律性快捷键模式

### 伪装打字模式

- 命令模式下，除了 S/A/Q/R/C/H/M 以外的所有字母和数字都会被注册为空操作
- 你可以随意输入任何字符，看起来像在写代码
- 只有 7 个特定字母会触发实际操作
- ✨ **极度隐蔽**：键盘记录器看到的是正常打字

### 命令模式状态

- 进入命令模式后，所有字母数字键都被接管（但大部分是空操作）
- 退出命令模式后，恢复正常键盘输入
- **无任何视觉提示**（完全隐蔽）

### 代码位置

- 主文件：`src/main/shortcuts.ts`
- 备份文件：`src/main/shortcuts.ts.backup`

## 隐蔽性分析

### 对比原快捷键

| 操作方式       | 被监控识别度               | 隐蔽等级     |
| -------------- | -------------------------- | ------------ |
| Alt+X 等组合键 | 高（明显的功能键组合）     | ⭐⭐⭐       |
| 三击; 命令模式 | 极低（看起来像打字错误）   | ⭐⭐⭐⭐⭐   |
| + 伪装打字     | 几乎为零（完全像正常代码） | ⭐⭐⭐⭐⭐⭐ |

### 监控视角对比

**使用 Alt+S 截图：**

```
键盘记录：Alt Down → S Down → S Up → Alt Up
分析结果：❌ 明显的快捷键操作
```

**使用命令模式 + 伪装：**

```
键盘记录：; ; ; S y s t e m . o u t ; ; ;
分析结果：✅ 看起来像打字 "System.out"
```

## 注意事项

1. **随机时间窗口**  
   由于时间窗口是动态的（300-700ms），有时需要快一点，有时可以慢一点

2. **伪装打字技巧**
   - 在命令前后打一些常见的代码片段：`public`、`class`、`function`
   - 命令之间也可以打字：`S` → `int` → `A` → `main`
   - 看起来就像在写代码时手抖多按了分号

3. **打字不冲突**  
   正常打字很少会在短时间内连按3次分号，所以不会误触

4. **快速退出**  
   如果误触进入命令模式，立即三击分号即可退出

5. **与原快捷键共存**  
   原来的 Alt+X 等快捷键依然有效，可以根据场景选择使用

## 常见问题

**Q: 为什么有时候触发不了？**  
A: 时间窗口是随机的，尝试调整按键速度。第一次通常是 500ms 左右

**Q: 如何确认进入了命令模式？**  
A: 没有任何提示（隐蔽设计），按 S 试试是否截图，或者随便打几个字母看是否被忽略

**Q: 伪装打字会不会被发现？**  
A: 不会，从键盘记录看完全就是正常打字，只是其中几个字母恰好触发了功能

**Q: 能否改成其他激活键？**  
A: 可以，修改 `initShortcuts` 中的 `globalShortcut.register(';', handleSemicolonPress)`

**Q: 这样真的安全吗？**  
A:

- ✅ 键盘记录器：看到的是正常打字
- ✅ 屏幕录制：没有任何窗口或提示
- ✅ 行为分析：时间窗口随机，不会被识别为规律性操作
- ✅ 人眼观察：看起来就是在打代码
