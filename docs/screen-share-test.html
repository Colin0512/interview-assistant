屏幕共享隐身测试

测试前提：截屏助手已经运行，窗口可见在屏幕上。

  1. 点下面的按钮
  2. 在弹窗里选 「整个屏幕」（不是窗口、不是标签页），点共享
  3. 看下方视频预览里，能不能看到截屏助手的窗口

怎么判断结果
  • 预览里看不到助手窗口（那块区域显示的是它背后的内容） → WDA_EXCLUDEFROMCAPTURE 生效，屏幕共享监考录不到它
  • 预览里助手窗口位置是黑色矩形 → 旧版遮挡模式，虽然录不到内容，但黑块本身很显眼
  • 预览里能正常看到助手窗口和里面的文字 → 内容保护没生效，屏幕共享监考能看到全部

注意：预览画面里会出现「预览里套预览」的无限镜像，这是正常的，不影响判断。
